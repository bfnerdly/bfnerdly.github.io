Flagship · Python · Pre-release

EthoCrypt

Keypoint-free, unsupervised behavior mapping of healthy and E. muscae-infected fruit flies. Segmentation with SAM 2, per-region DINOv2 features, optical flow, UMAP maps, and built-in reproducibility checks, run as Slurm batch jobs on Harvard's FASRC cluster.

  • PyTorch
  • SAM 2
  • DINOv2
  • OpenCV
  • UMAP
  • scikit-learn

Python · Behavioral analytics

Speed behavior analysis pipelines

Analysis package for multi-day locomotor tracking from MARGO arenas: actograms, 24 h autocorrelation, chi-square periodograms, survival-aligned activity around time of death, and spatial maps that check whether an intervention landed unevenly across a 4 × 32 arena grid. Configurable for infected and uninfected runs.

  • pandas
  • SciPy
  • seaborn
  • Time series

MATLAB · Elya Lab

BlindTOD

A measurement-bias audit, as a tool. It finds every cadaver in a tracking run, scrambles the arenas, and has me re-call each fly's time of death with box, date and genotype hidden. Comparing blinded with original calls tests for systematic bias in a key outcome metric.

  • MATLAB
  • Blinding
  • Bias audit
