EthoCrypt

Python + Rust · v{{ eth.version }} · pre-release

{% assign ids = "c2,c1" | split: "," %}{% include keys.html ids=ids %}

Keypoint-free, unsupervised behavior mapping of healthy and E. muscae-infected fruit flies, from hardware to verdict: a mirror rig and recorder, a desktop app for lab members with no coding experience, and a GPU cluster pipeline that discovers behaviors and tests each one for reproducibility.
